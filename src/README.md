# Тест-кейс 1: Создание клиента (Add Customer)
**Предусловие:**  
Пользователь находится на странице: `https://www.globalsqa.com/angularJs-protractor/BankingProject/#/manager`.

**Шаги:**
1. Нажать кнопку **Add Customer**.
2. Заполнить Post Code случайно сгенерированным числом из 10 цифр.
3. Заполнить поле **First Name** сгенерированным значением по правилу:
    - Разбить Post Code на двузначные числа
    - Преобразовать каждое число в букву. Например:
        - 00 → a (0 % 26 = 0 → a)
        - 01 → b
        - 25 → z
        - 26 → a (26 % 26 = 0)
        - 67 → k (67 % 26 = 15 → p)
    - Соединить все буквы в строку.
4. Заполнить поле **Last Name**.
5. Нажать кнопку **Submit**.

**Ожидаемый результат:**
- Клиент с введенными нами данными добавлен в таблицу **Customers**.
- Отображается окно с успешным созданием клиента.

# Тест-кейс 2: Сортировка клиентов по First Name
**Предусловие:**  
В системе есть несколько клиентов.  
Пользователь находится на странице: `https://www.globalsqa.com/angularJs-protractor/BankingProject/#/manager`.

**Шаги:**
1. Перейти на вкладку **Customers**.
2. Нажать на заголовок колонки **First Name** для сортировки по возрастанию.
3. Нажать еще раз для сортировки по убыванию.

**Ожидаемый результат:**
- Клиенты отображаются в алфавитном порядке по возрастанию/убыванию.

# Тест-кейс 3: Удаление клиента
**Предусловие:**  
В системе есть клиенты с именами разной длины.  
Пользователь находится на странице: `https://www.globalsqa.com/angularJs-protractor/BankingProject/#/manager`.

**Шаги:**
1. Перейти на вкладку **Customers**.
2. Извлечь список имен клиентов и их длин.
3. Рассчитать среднюю длину имен.
4. Найти клиента с длиной имени, ближайшей к средней.
5. Нажать кнопку **Delete** напротив выбранного клиента.

**Ожидаемый результат:**
- Клиент с длиной имени, ближайшей к средней, удален из таблицы.
